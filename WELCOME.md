## 🔧 Configuration Required

### Firebase Setup
1. Create Firebase project at firebase.google.com
2. Get your Firebase config
3. Update `js/firebase-config.js` with your credentials

### Optional: Email Hosting
1. Install Firebase CLI: `npm install -g firebase-tools`
2. Login: `firebase login`
3. Deploy: `firebase deploy`

## 💡 Pro Tips

1. **Use Developer Tools**
   - Press F12 to open DevTools
   - Console tab shows errors
   - Network tab shows requests
   - Elements tab shows HTML/CSS

2. **Test Multi-User Scenarios**
   - Use incognito/private browsing
   - Or use different browsers
   - Switch between teacher and learner

3. **Debug JavaScript**
   - Add `console.log()` statements
   - Set breakpoints in DevTools
   - Use `debugger;` keyword

4. **Responsive Testing**
   - Use DevTools device emulation (F12)
   - Resize browser window
   - Test on actual phone

## 🆘 Troubleshooting

| Issue | Solution |
|-------|----------|
| Page won't load | Check server is running, try different port |
| Styles not applying | Hard refresh (Ctrl+Shift+R) |
| Login not working | Check localStorage, clear cache |
| Firebase errors | Verify API key in firebase-config.js |
| Can't find file | Check spelling and path |
| Slow performance | Minimize unused modules, optimize images |
